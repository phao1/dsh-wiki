## 环境限制

当前环境的回环 socket 监听返回 `EPERM`。HTTP 用例通过内存双工流传递完整请求，由真实 Node HTTP 客户端和服务端解析。允许监听的环境会直接使用 `startServer` 启动回环服务。界面渲染模块与语法检查已通过，浏览器视觉和交互验收尚未执行。

GitHub 成功及部分失败场景使用注入的固定响应。当前 shell 无法解析 GitHub 公网域名，实时成功同步尚未验证。另已执行真实 CLI 同步失败路径：返回 `fetch failed`、退出码 1，持久化快照的 SHA-256 前后相同。
